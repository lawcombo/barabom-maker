# BARABOM STUDIO

브라우저 안에서 사진을 배치하고 꾸민 뒤 인화용 이미지 또는 PDF로 저장하는 React 기반 웹 사진 편집기입니다. 사용자 사진은 외부 서버로 전송하지 않으며, 프로젝트와 원본 이미지는 현재 브라우저의 IndexedDB에 저장됩니다.

공개 사이트: <https://lawcombo.github.io/barabom-maker/>

## 실행 방법

Node.js 20 이상을 권장합니다.

```bash
npm install
npm run dev
```

브라우저에서 Vite가 표시한 로컬 주소(기본값 `http://localhost:5173`)를 엽니다.

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

## 구현 기능

- 인생네컷 편집기와 독립적으로 동작하는 포스터 편집기
- 1~9컷, 세로·가로·그리드 레이아웃
- 클릭 업로드, 여러 사진 자동 배치, 컷별 드래그 앤 드롭
- 컷별 커서 기준 휠 확대/축소, 모바일 핀치 줌, 사진 위치 이동과 클리핑
- 회전, 좌우·상하 반전, 채우기/전체 맞춤, 밝기·대비·채도, 흑백·세피아
- JSON 데이터로 관리하는 실제 디자인 템플릿 22종
- 자유 텍스트, 한글 폰트, 추천 문구, 글자 스타일과 회전
- 기본 스티커와 사용자 PNG/WEBP 스티커
- 실행 취소/다시 실행, 복제, 삭제, 방향키 이동 단축키
- IndexedDB 자동 저장, 프로젝트 목록, 프로젝트 JSON 내보내기/가져오기
- PNG, JPG, PDF 다운로드와 브라우저 인쇄 미리보기
- 50×150mm, 2×6인치, 4×6인치, 사용자 규격 및 150/240/300DPI 렌더링
- 인쇄 안전 영역 표시와 반응형 모바일 패널
- 18개 카테고리, 54종 포스터 템플릿과 검색·방향 필터·즐겨찾기
- 포스터 이미지 슬롯, 사진 크롭·휠 줌·필터, 사용자 템플릿 배경 업로드
- 포스터 텍스트·한글 폰트·이모지·사용자 스티커·도형·QR코드
- 포스터 레이어 순서·잠금·숨김·복제·삭제와 전용 실행 취소/다시 실행
- A4/A3/SNS/사이니지 규격, PNG/JPG/PDF 고해상도 출력
- 인생네컷과 분리된 IndexedDB 포스터 프로젝트 저장 및 JSON 가져오기/내보내기

## 편집 조작

- 사진을 클릭하고 드래그: 컷 안에서 위치 조정
- 사진 위 마우스 휠: 커서 위치를 기준으로 해당 사진만 확대/축소
- 모바일 두 손가락: 선택한 컷의 사진 핀치 확대/축소
- `Ctrl+Z`: 실행 취소
- `Ctrl+Shift+Z` 또는 `Ctrl+Y`: 다시 실행
- `Ctrl+C`: 선택 요소를 빈 컷 또는 새 레이어로 복제
- `Delete`: 선택 요소 삭제
- 방향키 / `Shift+방향키`: 텍스트·스티커 위치 미세 조정

## 인화 규격

| 규격 | 크기 | 300DPI 기준 |
| --- | --- | --- |
| 인생네컷 | 50×150mm | 약 591×1772px |
| 2×6인치 | 50.8×152.4mm | 600×1800px |
| 4×6인치 | 101.6×152.4mm | 1200×1800px |

다운로드는 DOM 화면 캡처가 아니라 Konva 편집 장면을 선택 규격의 픽셀 비율로 다시 렌더링합니다. 웹폰트 로딩 완료 후 출력하며, PDF는 선택한 mm 규격으로 생성됩니다.

## 프로젝트 구조

```text
src/
├─ components/
│  ├─ CanvasStage.tsx  # Konva 렌더링, 컷 클리핑과 제스처
│  ├─ Editor.tsx       # 편집 상태, 패널, 저장과 출력
│  └─ Landing.tsx      # 최초 편집 종류 선택
├─ data/
│  ├─ layouts.ts       # 1~9컷 레이아웃 계산
│  └─ templates.ts     # 22종 JSON 템플릿 데이터
├─ lib/
│  ├─ document.ts      # 편집 문서 생성과 이미지 읽기
│  └─ projects.ts      # IndexedDB 프로젝트 저장소
├─ modules/poster/
│  ├─ PosterStart.tsx  # 포스터 시작·템플릿 탐색 화면
│  ├─ PosterEditor.tsx # 포스터 편집 상태·패널·저장·출력
│  ├─ PosterCanvas.tsx # 포스터 전용 Konva 캔버스
│  ├─ templates.ts     # 54종 포스터 템플릿 데이터
│  ├─ storage.ts       # 포스터 전용 IndexedDB 저장소
│  ├─ types.ts         # 포스터 전용 데이터 모델
│  └─ poster.css       # 포스터 모듈 범위 스타일
└─ types.ts            # 인생네컷 편집 데이터 모델
```

## 포스터 편집기 사용 방법

1. 메인 화면에서 `포스터 만들기`를 선택합니다.
2. 54가지 디자인 템플릿, 내 템플릿 업로드, 빈 캔버스 중 하나로 시작합니다.
3. 왼쪽 메뉴에서 사진·텍스트·스티커·도형·배경·레이어를 편집합니다.
4. 사진 슬롯을 클릭하거나 이미지를 캔버스에 드롭하고, 휠로 사진을 확대합니다.
5. 프로젝트 메뉴에서 브라우저에 저장하거나 전용 JSON 파일로 내보냅니다.
6. 다운로드에서 PNG, JPG, PDF 형식을 선택해 저장합니다.

포스터 프로젝트는 `barabom-poster-studio/poster_projects` 저장소를 사용하므로 기존 인생네컷 프로젝트와 섞이지 않습니다.

## 확장 방향

`EditorDocument`는 사진, 텍스트, 스티커, 프레임, 출력 규격을 분리합니다. 포스터나 매장 전용 템플릿은 새 편집 문서 타입과 레이아웃 생성기를 추가해 확장할 수 있습니다. 프린터 연결은 현재 `exportImage`/`printDesign` 경계를 별도 출력 서비스로 옮기면 됩니다.

## 알려진 제약

- 브라우저 인쇄의 물리 크기는 프린터 드라이버와 브라우저 배율 설정에 영향을 받습니다. 인쇄 대화상자에서 배율 100%와 여백 없음을 확인해야 합니다.
- 매우 큰 원본 이미지를 여러 장 저장하면 브라우저 IndexedDB 용량 제한에 도달할 수 있습니다.
- 현재는 단일 사용자 로컬 프로젝트이며, 클라우드 동기화와 포토프린터 직접 제어는 포함하지 않습니다.
